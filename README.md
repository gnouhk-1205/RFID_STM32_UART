**RFID_STM32_UART**

A comprehensive hardware-to-software solution for RFID access control. This system seamlessly integrates an STM32 microcontroller with a custom UART interface and an intuitive C# desktop GUI for real-time card management and logging.

**Key Features**

- Robust communication between the STM32 and RDM6300 125kHz RFID reader modules.
- Custom UART hardware interface for reliable, high-speed data transmission.
- Interactive C# WinForms desktop application for real-time tag reading and access logging.
- Seamless device monitoring and status tracking.

**System Requirements**

- **Hardware:** STM32 Microcontroller, RDM6300 125kHz RFID Module, USB-to-UART Adapter (e.g., CH340).
- **Software:** Windows 10/11, .NET Framework 4.7.2 or higher, Visual Studio 2022.
